
# 🌌 AstroTrainer

**Train your eyes. Explore the sky. Prepare for the stars.**

AstroTrainer is a free, interactive astronomy training platform built to help students prepare for astronomy olympiads, including the **International Olympiad on Astronomy and Astrophysics (IOAA)**.

From identifying constellations and recognizing stars to exploring an interactive sky map and locating Messier objects, AstroTrainer brings observational astronomy practice into one place.

**🌐 Live demo:** [astrotrainer.vercel.app](https://astrotrainer.vercel.app/)

---

## ✨ Features

### 🌠 Constellation Practice

Learn to recognize all 88 IAU constellations through multiple difficulty levels.

- **Beginner:** Practice with constellation stick figures and multiple-choice questions.
- **Intermediate:** Identify constellations with additional sky-map context.
- **Advanced:** Test your knowledge by entering constellation names without multiple-choice hints.
- **Official IAU Images:** Practice recognition using official constellation illustrations.

### ⭐ Star Practice

Develop your ability to identify stars and locate them in the night sky.

- Identify stars by their common or traditional names.
- Practice recognizing stars using Bayer designations.
- Train with different difficulty levels.
- Practice locating stars through progressively more challenging exercises.

### ✨ Asterism Practice

Test your recognition of familiar star patterns and asterisms. Build familiarity with the patterns that help observers navigate the night sky.

### 🔭 Messier Objects

Practice recognizing and locating objects from the Messier catalogue.

- Explore Messier objects through dedicated practice activities.
- Challenge yourself to locate objects by identifying their positions on the sky map.
- Build familiarity with prominent deep-sky targets.

### 🗺️ Interactive Sky Map

Explore the sky through an interactive map designed for learning and observation.

Depending on the enabled overlays, explore:

- Constellation lines and labels.
- IAU constellation boundaries.
- Equatorial coordinate grid.
- Ecliptic and celestial equator.
- Galactic equator.
- Celestial and galactic poles.
- Vernal and autumnal equinox markers.
- Messier object markers and labels.
- Asterism lines and labels.

Navigate the map using zoom, pan, and rotation controls, and customize the displayed overlays to focus on the features you want to study.

### 🎯 Built for Astronomy Olympiad Preparation

AstroTrainer is designed around the recognition and sky-navigation skills that are useful in observational astronomy competitions. It can also be used by anyone interested in learning the night sky.

## 🚀 Getting Started

### Try AstroTrainer Online

Visit **[AstroTrainer](https://astrotrainer.vercel.app/)** to start practicing without setting up a local development environment.

### Run Locally

You'll need [Node.js](https://nodejs.org/) and npm installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/SurjoX/astrotrainer.git
   cd astrotrainer
   ```

2. Install the dependencies:

   ```bash
   npm install
   ```

3. Check the available scripts in `package.json`:

   ```bash
   npm run
   ```

4. Start the development server using the development script defined in `package.json`. For example, if the project defines a `dev` script:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by the development server in your browser.

> **Note:** Available scripts and deployment commands may change as the project evolves. Refer to `package.json` and the current project configuration for the authoritative commands.
